# Aurora

Fundo translúcido em toda a tela.

**[Abrir o Aurora →](https://romastefale.github.io/aurora/)**

O mesmo véu do Gradients: manchas suaves que se misturam sobre o papel claro ou o preto do modo escuro. Aqui ele ocupa a tela inteira do aparelho, sem moldura, e muda de desenho e de cor bem devagar.

O claro e o escuro seguem o modo do sistema.
